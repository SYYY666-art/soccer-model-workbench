## 2. 二维轴对称网格敏感性（01–03）

| 网格 | 域单元数 | 轴向总阻力 (N) | 压差阻力 (N) | C_D |

- 更细 → 极细总阻力降幅约 **17.8%**，几乎全部来自压差贡献（黏性余项 0.512 → 0.512 N 几乎不变）。
- 结论：阻力对尾流/边界层分辨高度敏感，论文报告三维力数据必须注明网格版本并讨论敏感性。

## 3. 三维瞬态力（06–08）

### 数据清洗（README §3）
- 研究 2 的 0 s 首帧（Fx ≈ 203.9 N）与研究 3、研究 4 的 0.020 s 首帧（Fx ≈ 264.7 N）为启动/续算伪影，已剔除。
- 零转合并时序：研究 2 取 0.002–0.020 s，接研究 3 取 0.022–0.040 s。
- 平台期比较窗口：**0.024–0.040 s**（自旋平台之后）。

### 平台期平均力与系数

| 工况 | Fx (N) | Fy (N) | Fz (N) | C_D | C_L |
|---|---:|---:|---:|---:|---:|
| 零转 | 2.896 | +0.711 | +0.409 | 0.126 | +0.031 |
| 正转 ωz=+50 | 2.917 | −0.608 | +0.407 | 0.127 | −0.026 |
| 反转 ωz=−50 | 3.070 | +1.902 | +0.387 | 0.133 | +0.083 |

末帧（0.040 s）核对值：零转 Fy = +1.157 N，正转 Fy = −2.131 N，反转 Fy = +4.130 N，
正/反转相对零转 ΔFy 分别为 −3.289 N / +2.973 N（与 README 核对表一致）。

### 关键发现 1：反向 Magnus 效应
- 来流沿 +x、正转 ωz=+50 rad/s 时，经典 Magnus 方向 ω×u = **+y**，但实测 ΔFy < 0；
  反转实测 ΔFy > 0。两者均与经典方向**相反**。
- 解释：Re ≈ 4.7×10⁵ 处于足球临界区，边界层转捩位置随旋转不对称，可产生反向侧力。
- 对实验台的约束：A 管线的 Ω_eff×u 项方向固定为经典方向，**不能表征反向 Magnus**，
  反演所得 Ω_eff 只能解释为低阶有效参数（论文 §5.4 已有约束，此处得到数值证据）。

### 关键发现 2：侧向力几乎全部来自压力
- 零转平台期：压力贡献占 Fx 的 **83%**，占 Fy 的 **100%**。
- 侧向力本质是球面压力分布不对称 → 与 A 管线"用横向有效旋转压缩压力不对称效应"的
  低阶参数化思路自洽。

## 4. 与实验台反演结果的量级对照

- **C_D**：COMSOL 光滑球 0.126 vs A-2 管线反演典型值 ≈ 0.31。差异来源：
  ① 真实足球拼缝/面板粗糙度使超临界阻力高于光滑球；② 反演参数吸收建模与观测误差。
- **有效旋转**：实测 C_L 折合为经典参数化等效 |Ω_eff| = (ρA/2m)·C_L·U∞：
  反转平台平均 ≈ 0.14 s⁻¹，末帧瞬时 ≈ 0.31 s⁻¹，与实验台反演 Ω_eff 的典型量级可比。
