# COMSOL 数据交付格式（发给 CFD 队友）

> 实验台 C 管线（`comsol_bridge.py`）的数据接口规范，对应论文 §4.3.4 与附录 B。
> 导出时按本文件约定即可直接接入实验台，无需再转换。

## 1. 首选交付：气动系数工况表（CSV，UTF-8）

每个计算工况一行，文件头（列名）必须完全一致：

```csv
Re,S,orientation,C_D,C_L,C_S,C_D_std,C_L_std,C_S_std,grid_version
4.68e5,0.000,0,0.181,0.000,0.000,0.002,0.001,0.001,fine_v2
4.68e5,0.120,0,0.184,0.042,0.003,0.002,0.002,0.001,fine_v2
4.68e5,-0.120,0,0.184,-0.041,0.002,0.002,0.002,0.001,fine_v2
4.30e5,0.000,0,0.176,0.000,0.000,0.002,0.001,0.001,fine_v2
```

### 字段定义

| 列 | 含义与公式 |
|---|---|
| `Re` | 雷诺数，Re = ρ·D·\|U∞\|/μ（D=0.22 m，ρ=1.225，μ=1.81e-5） |
| `S` | 无量纲旋转比，S = R·\|ω\|/\|U∞\|（R=0.11 m；ω 用 rad/s） |
| `orientation` | 球面拼缝朝向标记（若未建模朝向，填 0） |
| `C_D` | 阻力系数，C_D = F·e_D/(q∞A)，e_D 沿来流方向 |
| `C_L` | 升力系数，C_L = F·e_L/(q∞A)，e_L 沿 ω×U∞ 方向（右手定则） |
| `C_S` | 侧力系数，C_S = F·e_S/(q∞A)，e_S = e_D × e_L |
| `C_D_std` 等 | 瞬态时间平均的波动标准差（稳态解填 0 或留空） |
| `grid_version` | 网格版本号（如 `fine_v2`），供网格无关性审计 |

其中 q∞ = ½ρ\|U∞\|²，A = πR²。**所有系数都用动压与参考面积归一化**，
不要用 NASA 教学页的 c_N 经验因子定义，也不要混用 rev/s 与 rad/s。

### 方向与符号约定

- 来流沿 **+x**；球旋转轴按 COMSOL 全局坐标填写；
- 无自旋工况的 C_L、C_S 应接近零（作为积分正确性的自检）；
- 旋转工况的 C_L 符号必须与 ω×U∞ 一致，导出前自查一次。

## 2. 工况覆盖建议（覆盖飞行全程的查询区间）

飞行中球速约 30 → 26 m/s：

- **Re 轴**：至少 3~4 个点，如 4.0e5、4.3e5、4.7e5、5.0e5（改 U∞ 实现）；
- **S 轴**：至少 0、±0.06、±0.12（对应 ω≈±17、±34 rad/s，即约 ±3、±5.5 rev/s；
  若想覆盖强烈弧线球再加 ±0.20，约 9 rev/s）；
- 正、反自旋都要跑（对称性检查：C_L(S) ≈ −C_L(−S)）。

二维轴对称数据只对应 S=0、Re=4.68e5 的零自旋工况，直接填进上表即可。

## 3. 备选交付（任选其一即可）

- **原始球面力时间曲线**：若不想自行积分，每个工况导出 `t, F_x, F_y, F_z`
  三列表 + 一个说明文件（该工况的 Re、S、ω 向量、orientation、grid_version）。
  我来做时间窗平均并换算成 §1 的系数表。
- **散点工况表**：工况不全也没关系，只要每行是"一个 Re 配一个 S"的散点即可，
  实验台会改用散点插值（当前实现按完整 Re×S 网格读取，我会同步增强兼容性）。

## 4. 网格与收敛信息（论文审计用，随 CSV 一起给）

每份 CSV 配一段说明或一个 `README`，至少包含：

1. 湍流模型与近壁处理（如 SST k-ω / 标准 k-ε、壁面函数、y⁺ 范围）；
2. 球面几何（光滑球？有无面板/拼缝简化）——**必须写明"光滑球基准"**；
3. 粗/中/细网格节点数、相邻网格 C_D 相对差（二维已知 17.8%，三维报实际值）；
4. 瞬态时间窗与平均区间、力系数监测是否稳定；
5. 计算域尺寸与阻塞效应检查结果；
6. 稳态不收敛的说明（如有）——论文按瞬态平均结果解释即可。

## 5. 命名与归档建议

```
data/
  comsol_table.csv            # §1 主表（实验台直接读取）
  comsol_notes.md             # §4 的网格/收敛说明
  axisym_initial_field.txt    # 已有二维初始场，留档
```

实验台侧：上传 `comsol_table.csv` 后 C 管线自动启用，
越界工况查询会给出"外推警告"而不是静默外推。

## 6. 瞬态球面力时间曲线（备选交付 C 的格式）

若导出原始力曲线，每个工况一个文件，命名如 `forces_Re468000_S_plus012.csv`：

```csv
t,F_x,F_y,F_z
0.0000,0.0000,0.0000,0.0000
0.0002,0.9821,0.0001,-0.0012
0.0004,0.9755,0.0002,-0.0008
...
```

配套一个 `cases.txt` 说明每个文件对应的工况：

```text
forces_Re468000_S_0.csv        Re=4.68e5, S=0.000, omega=(0,0,0) rad/s,      fine_v2
forces_Re468000_S_plus012.csv  Re=4.68e5, S=0.120, omega=(0,0,34.3) rad/s,  fine_v2
forces_Re468000_S_minus012.csv Re=4.68e5, S=-0.120, omega=(0,0,-34.3) rad/s, fine_v2
```

由实验台侧完成：时间窗平均（取后段平稳区间）→ 无量纲化
（除以 q∞A = ½ρ|U∞|²·πR²）→ 按 §1 符号约定投影得到 C_D/C_L/C_S。

4.68e5,-0.120,0,0.184,-0.041,0.002,0.002,0.002,0.001,fine_v2
4.30e5,0.000,0,0.176,0.000,0.000,0.002,0.001,0.001,fine_v2
4.30e5,0.120,0,0.179,0.039,0.002,0.002,0.002,0.001,fine_v2

> 否则散点插值凸包退化、查询会落空并触发外推警告。

## 8. 常见换算与符号错误（自查清单）

| 易错点 | 正确做法 |
|---|---|
| NASA 教学页 c_N≈0.25 | 那是经验修正因子且用 rev/s，不能当动压归一化 C_L 用 |
| ω 单位 | 一律 rad/s；S=R·\|ω\|/\|U∞\| 无量纲 |
| C_L 方向 | 必须沿 ω×U∞（右手定则）；正自旋→正 C_L，导出前验证符号 |
| 压力符号 | C_D 用球面积分 F·e_D/q∞A，压力项注意法向方向，别把阻力算成推力 |
| 参考面积 | A=πR²（迎风截面），R=0.11 m，不要用球表面积 4πR² |
| 密度黏度 | 与论文一致：ρ=1.225 kg/m³、μ=1.81e-5 Pa·s（25°C 空气） |
| 无自旋工况 | C_L、C_S 应 <1e-3；不满足说明积分或网格对称性有问题 |
| 正反对称 | C_L(S)≈−C_L(−S) 是必要的对称性自检 |

## 9. 交付自检表（发给队友前逐项打勾）

- [ ] CSV 表头与 §1 完全一致（大小写、下划线）
- [ ] 每个工况一行，同一 (Re,S) 不重复
- [ ] 至少 2 个 Re 水平 × 3 个 S 水平（含零自旋基准）
- [ ] C_L/C_S 符号按 ω×U∞ 右手定则验证过
- [ ] 无自旋工况 C_L、C_S≈0
- [ ] 系数由时间平均给出（瞬态）并附波动标准差
- [ ] 附 §4 的网格/收敛说明（模型、y⁺、网格差、瞬态区间）
- [ ] 注明"光滑球基准"（如未建模面板/拼缝）
- [ ] 文件名与 grid_version 可追溯

## 10. 数据到位后实验台的验收流程

1. 上传 `comsol_table.csv` → C 管线自动启用，侧边栏显示已加载与 grid_version；
2. 用题目两帧数据跑 C 管线，与 A-2/B 结果并列出现在模型包络表；
3. 检查 3D 图与卡片是否出现"外推警告"（若飞行 Re 超出图谱覆盖域，说明 §2 工况需要加密）；
4. 跑 `python validation_suite.py` 做异模型盲测：以 C 管线为真值生成器、A/B 反演，
   输出论文 §9.2 所需的跨模型落点误差表。

## 11. 建议工况矩阵总表（按此表跑，交付最完整）

飞行 Re 区间约 4.0e5 ~ 5.0e5。名义来流 U∞=31.46 m/s（对应 Re≈4.68e5）。
推荐 **3 个 Re 水平 × 5 个 S 水平 = 15 个工况**（零自旋 + 正反自旋各两档）：

| 工况 | U∞ (m/s) | ω (rad/s) | ω (rev/s) | Re | S |
|---|---|---|---|---|---|
| 基准 0 | 31.46 | 0 | 0 | 4.68e5 | 0.000 |
| 低自旋 + | 31.46 | +17.2 | +2.7 | 4.68e5 | +0.060 |
| 低自旋 − | 31.46 | −17.2 | −2.7 | 4.68e5 | −0.060 |
| 高自旋 + | 31.46 | +34.3 | +5.5 | 4.68e5 | +0.120 |
| 高自旋 − | 31.46 | −34.3 | −5.5 | 4.68e5 | −0.120 |
| 高速组（同上 5 档） | 33.6 | 0, ±18.3, ±36.6 | — | 5.0e5 | 0, ±0.06, ±0.12 |
| 低速组（同上 5 档） | 26.9 | 0, ±14.7, ±29.3 | — | 4.0e5 | 0, ±0.06, ±0.12 |

（若算力有限：先交付 §7 的 2×3 最小样例，再逐档加密。）

## 12. 二维轴对称数据交付（论文"网格敏感性"小节用）

已有二维结果只需补一张表（放进 `comsol_notes.md`）：

```markdown

|---|---|---|---|---|---|
| 细 | … | … | … | … | — |
| 更细 | … | … | … | … | … |
| 极细 | 7756 | … | … | … | −17.8% |
```

说明文字（论文可参考）："从更细网格到极细网格，计算阻力下降 17.8%，
差异几乎全部来自压力贡献，表明当前阻力结果仍对网格敏感；
三维气动力以瞬态时间平均结果报告，并附网格版本号。"

## 13. COMSOL 侧导出操作要点

1. **球面力积分**：结果 → 派生值 → 表面积分，对球面选
   `spf.T_stressx` 等方向分量（或用全局变量探针），输出 F_x, F_y, F_z；
2. **参数扫描**：建议用"辅助扫描"一次跑完同一 Re 下的多档自旋，
   避免每档重建研究；每个工况务必记录求解时间与日志；
3. **导出表格**：结果 → 导出 → 数据，选"表格"格式；
   系数由力/（q∞A）手算或导出后用脚本换算均可（我也可以代劳，见 §6）；
4. **瞬态平均**：取力曲线后段平稳窗口（如 0.010–0.020 s）做均值与标准差，
   起步段瞬态不要计入；
5. **单位检查**：COMSOL 内力的默认单位是 N/m（二维）与 N（三维）；
   三维积分结果才直接对应球面总力。
