# UPC 2026 B 题 COMSOL 交接说明

2026 年 11 月 7 日 · 点球轨迹预测 · COMSOL Multiphysics 6.4.0.293

本目录记录二维轴对称网格比较、三维初始场的来源，以及三维光滑球在同一来流下的零转、正转和反转瞬态结果。CSV、TXT 和 PNG 均按各自用途从 COMSOL 导出。文件名用中文编号，CSV 保留 COMSOL 原表头，报告用图的文字为英文。

清单按导出时约定的文件名编写。若实收名称略有出入，先用编号、文件类型、表头、时间和图内单位核对对应关系。下文给出的数值是显示精度下的核对值，分析时读取实际收到的 CSV。

初始场文件的列为 `r,z,u,w,p,k,ep`。两列坐标单位为 m，二维 `u` 是径向速度，`w` 是轴向速度，均为 m/s。`p` 是压力（Pa），`k` 是湍动能（m²/s²），`ep` 是湍流耗散率（m²/s³）。三维来流改沿 +x，因此二维的轴向速度 `w` 映射为三维 x 向速度，二维的径向速度 `u` 投影到三维 y、z 方向。

## 3. 三维力表怎么读、怎么算

### 参数、坐标和单位

- 光滑球半径 **0.11 m**，直径 **0.22 m**，球心在原点。球面拼缝和面板朝向未建模，`orientation=0`。本批使用标准 k–ε 与壁函数，三维网格标记 `3d_mesh_v1`。
- 来流 **31.46 m/s**，沿三维全局 **+x**。空气密度 **1.225 kg/m³**，动力黏度 **1.81×10⁻⁵ Pa·s**，`Re=ρUD/μ≈4.684×10⁵`。x 是轴向，y 是侧向，z 是竖向。
- 正、反转都绕全局 z 轴，角速度向量的平台值分别为 `(0,0,+50)`、`(0,0,-50)` rad/s。旋转从 **0.020 s** 平滑起步，在 **0.024 s** 达到平台。有符号旋转比 `S=ωzR/U` 为 **±0.17483**。模型参数 `Sp_ball` 用绝对值，旋向从 `omg_ball` 的符号读取。
- 三维总力表中的「轴向阻力」「侧向力」「竖向力」分别对应 `Fx,Fy,Fz`，单位 **N**。力积分的边界为球面 6–13，表达式为 `-spf.T_tracx`、`-spf.T_tracy`、`-spf.T_tracz`。
- 文件名用 ms，CSV 时间列用 **s**。表中的球面面积约 **0.15190 m²**，用于检查积分选面。计算力系数的参考面积用球的迎风截面 **A = πR² ≈ 0.038013 m²**，归一化分母 **½ρU²A ≈ 23.044 N**。

### 清理原始时序与工况对齐

1. **保留原始 CSV。** 读出时间、球面面积和三个力分量。如果文件前面有 COMSOL 的说明行，识别出真实表头后再读取数值。按文件分别核对时间、列数和末帧。完整输出的每段有 11 个时刻，间隔为 0.002 s。
2. **单独标记异常首帧。** 研究 2 的 0 s 行，轴向力约 **203.90 N**。研究 3 和两份研究 4 的 0.020 s 首帧，轴向力约 **264.72 N**。这些行留给启动和续算诊断。合并零转时序时，从研究 2 取 **0.002–0.020 s**，再接研究 3 的 **0.022–0.040 s**。自旋时序从 **0.022 s** 开始绘制，平台期比较取 **0.024–0.040 s**。
3. **在同一时刻比较三组力。** 先列带符号的全局 `Fx,Fy,Fz`。如需看旋转相对基准的影响，分别算 `ΔFy(正)=Fy(正)−Fy(零)`、`ΔFy(反)=Fy(反)−Fy(零)`。零转的横向分量照实保留。瞬时无量纲分量可按 `Cx=Fx/23.044`、`Cy=Fy/23.044`、`Cz=Fz/23.044` 计算。
4. **压力表单独比较。** 压力贡献表的三向结果是已经对球面积分过的力，单位 N。与总力按相同时刻对齐相减，可得总力中扣除压力贡献后的余项。压力云图展示的是 Pa，球面压力积分表展示的是 N。

### 怎样用于论文和轨迹模型

这批数据可用于报告中的二维网格敏感性和三维短时自旋对照。在相同来流和起始流场下，正转与反转相对于零转产生了方向相反的侧向力变化。正反转的侧向力差绝对值从 **0.038 s 的约 5.07 N** 增至 **0.040 s 的约 6.26 N**，引用末帧数值时标注其为瞬时值。当前只有一个 Re，三维网格和时间步敏感性、代表性平均窗口仍待验证。

队友接口规范的 §6 接受力时程。若需要整理成该格式，可另外生成每个工况一份的 `t,F_x,F_y,F_z`，附 Re、带符号 S、角速度向量、`orientation` 和 `grid_version`。若要生成轨迹模型使用的多工况系数查表 `comsol_table.csv`，先验证平均窗口、覆盖多个 Re，再统一风洞来流方向与球相对空气速度方向的定义，以及旋转轴和力的投影方向。
